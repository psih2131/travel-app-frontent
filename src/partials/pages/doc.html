Политика конфиденциальности

Настоящая политика конфиденциальности определяет порядок обработки и защиты персональных данных пользователей сервиса. Использование сайта означает ваше согласие с условиями настоящего документа.

1. Общие положения

Мы собираем только те данные, которые необходимы для оказания услуг: имя, контактный адрес электронной почты, номер телефона. Персональные данные не передаются третьим лицам без вашего согласия, за исключением случаев, предусмотренных законодательством.

2. Цели обработки данных

Обработка персональных данных осуществляется в следующих целях:

  • оформление и исполнение заказов на туры и экскурсии;
  • связь с вами по вопросам бронирования;
  • улучшение качества сервиса и контента сайта;
  • рассылка информационных сообщений (при наличии согласия).

3. Защита данных

Мы применяем технические и организационные меры для защиты ваших данных от несанкционированного доступа, изменения или уничтожения. Доступ к персональным данным имеют только уполномоченные сотрудники.

Если у вас возникли вопросы по обработке персональных данных, вы можете написать нам по адресу поддержки или через форму обратной связи на сайте.

3.1. Файлы cookie

Сайт может использовать файлы cookie для обеспечения работы сервиса и анализа посещаемости. Отключение cookie может ограничить функциональность сайта.

4. Контакты

По вопросам политики конфиденциальности обращайтесь: support@example.com или через раздел Поддержка.
